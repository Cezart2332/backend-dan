# Site Dan - Recreere Premium

Acest proiect reprezintă o recreere modernă și premium a site-ului `danfostanxios.ro`, construit folosind **Vite + React**.

## Tehnologii folosite
- **React**: Core framework
- **Framer Motion**: Pentru animații premium și smooth transitions
- **Lucide React**: Set de iconițe curate și moderne
- **Vanilla CSS**: Design complet personalizat, fără framework-uri de utilități, pentru control maxim asupra esteticii.

## Caracteristici Design
- **Paletă de culori**: Alb pur și Albastru deschis (Light Blue), inspirată din aplicația mobilă.
- **Tipografie**: Utilizarea fontului 'Outfit' pentru un look modern și lizibil.
- **Smooth Scrolling**: Navigare fluidă între secțiuni.
- **Premium Feel**: Utilizarea de blur effects (backdrop-filter), animații de tip floating, și gradienturi subtile.

## Structură Secțiuni
1. **Hero**: Mesaj puternic de impact cu statistici și acțiuni rapide.
2. **Despre**: Povestea personală a lui Dan, cu accente vizuale premium.
3. **Tehnica HAI**: Explicație vizuală a celor 3 pași fundamentali.
4. **Cărți**: Secțiune de e-commerce curată pentru Volumul I și II.
5. **Promo App**: Card integrat pentru promovarea aplicației mobile.
6. **Footer**: Navigare completă, linkuri legale și contact.

## Cum se rulează
1. `npm install` (deja efectuat)
2. `npm run dev`
